How It Works in the App

No typing IP addresses or configuring FTP ports. Everything is handled behind an instantaneous 3D QR handshake.

1
Select Files
Open QRFlux on your Android phone and tap Send Files. Select any number of photos, 4K videos, documents, or apps.
2
Show Dynamic QR
The app binds a local high-performance streaming engine and generates an ephemeral QR code with an instant 6-digit verification code.
3
Scan on Receiver
On the second phone, open QRFlux and tap Receive Files. Point your camera at the QR code to pair in 0.2 seconds.
4
Stream at 50+ MB/s
Files stream directly over raw TCP sockets straight into your phone's Downloads directory at full local Wi-Fi speeds!

💻 DESKTOP COMPANION GUIDE

Want to Send Files from Laptop or PC to Phone?

QRFlux is mainly built as a mobile app. If you want to beam files from your computer to your phone, install this repo locally and launch the local PC Host!

Why run locally instead of using a web browser in the cloud? Cloud websites cannot stream raw TCP data directly to your phone's private Wi-Fi IP address due to browser security sandbox rules (Private Network Access & Mixed Content). Running the lightweight host server on your machine gives you native, unthrottled 50+ MB/s transfer speeds directly from your computer to your phone.
1

Clone or Download the Repository

Open your terminal or PowerShell and clone the QRFlux repository to your computer:

git clone https://github.com/Ganesh-anandam/qrflux.git
2

Ensure Dart SDK is Installed

The PC Host is powered by Dart. If you have Flutter installed, Dart is already available. Check your installation:

dart --version
3

Run the PC Host Server

Start the local transfer engine. It automatically finds your Wi-Fi IP and launches your browser:

Windows

Simply double-click run_pc_host.bat inside the project folder, or run:

dart run bin/server.dart
macOS / Linux
dart run bin/server.dart
💡 Windows Firewall note: If prompted, click "Allow access", or run fix_firewall.bat as Administrator.
4

Drop Files in the Local Web Interface

Your default browser will automatically open http://localhost:8080. Drag & drop any files (movies, photos, zip archives, folders) and click Generate Transfer QR.

5

Scan with the QRFlux Android App

Make sure your phone is connected to the same Wi-Fi network (or connect your PC to your phone's hotspot). Open the QRFlux Android App, tap Receive Files, and point the camera at your PC screen. Your files will stream directly to your phone at 50+ MB/s!
